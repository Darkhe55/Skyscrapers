# 高楼 Skyscrapers

一个基于 Web 的高楼（Skyscrapers）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5192/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 在 n×n 格中填入 1..n，每行每列数字不重复
- 盘外数字表示从该方向看去能看到的高楼栋数
- 高楼会挡住后面的矮楼

## 操作

| 操作 | 说明 |
|------|------|
| 左键点格 | 选中格子 |
| 数字键 1–9 / 0 或 Backspace | 填数 / 清除 |
| 右键点格 | 清除该格 |
| 方向键 | 移动选中格 |
| 滚轮 / 中键拖拽 | 缩放 / 平移画布 |
| Z / Shift+Z / Y | 撤销 / 重做 |
| C / H / S / Esc | 检查 / 提示一格 / 显示解 / 清空 |
| R / L / P / M | 随机抽题 / 逻辑解题 / 暂停回放 / 音效开关 |
| 0 / + / - | 视图复位 / 放大 / 缩小 |

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由；优先使用可证明的安全定式，推不动时才反证 / 回溯；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 逻辑解题规则（安全定式）

逻辑引擎只做**可证明的局部约束**（只排除一定不成立的候选），不做猜测；反证与回溯仅作兜底：

| 规则名 | 说明 |
|--------|------|
| 盘外线索极值 `clue` | 线索 1 = 紧邻该侧就是最高楼 n；线索 n = 从该侧 1..n 单调递增 |
| 可见性排列 `visible` | 枚举满足该行 / 列两侧线索的全部排列，按候选格取交集做交叉消除（4–6 阶全排列 ≤ 720 种） |
| 拉丁方 `latin` | 行 / 列唯一候选（naked single）、隐藏单值（hidden single） |
| 候选数对 / 三元组 `subset` | 行 / 列内两三个格子的候选并集恰为 2 / 3 个数时，从该行 / 列其余格排除 |
| 可见高度上下界 `bound` | 7 阶以上不枚举全排列，改用单侧线索的 DP 计算每格可取值（含最高楼位置上下界） |

- 兜底顺序：定式推满 → 逐格反证（`probe`）→ 回溯搜索（`search`）。
- 内置 6 题均可**纯定式推满**（不需要反证 / 回溯）；`npm run check` 会逐题输出是否用到反证与唯一解搜索节点数。
- 限制：4–6 阶用整行 / 整列排列枚举；7–9 阶改用上下界 DP（强度略弱但避免 n! 爆炸），仍由反证 / 回溯兜底。

## 图片导入题库（识图 CLI）

```bash
npm run import-image -- month.png                # 识别并预览（不写入）
npm run import-image -- month.png --verify       # 额外求解 / 唯一性检查（9×9 也可能较慢，超时只警告）
npm run import-image -- month.png --append       # 写入 src/game/imported-puzzles.ts
npm run import-image -- month.png --json out.json  # 导出识别结果
```

- 全自动识图：Playwright + 本机 Edge 取像素 → 白格内部连通域定位 n×n 格（原题是格子间留空隙的样式）→
  灰色气泡连通域定位 4n 个盘外提示位 → 格内数字 / 气泡内数字分别做字形聚类 + 多字体多字号模板匹配。
- 结构校验：预填与盘外提示必须在 0..n 范围内；仍不确定时用 `--map 簇号=数字` 覆盖字形簇判读，
  或 `--fix "cell:列,行=值,top:i=值,bottom:i=值,left:i=值,right:i=值"` 覆盖具体数值。
- 导入题写入 `src/game/imported-puzzles.ts`，`npm run gen` 不会覆盖；游戏启动时会与内置题一起加载。
- 限制：`--verify` 会调用项目 solver 检查唯一性，9×9 也可能需要较多节点，超时只警告；
  未带参考解时「显示解 / 提示一格」依赖求解器现场计算。

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 项目结构

```
src/
  main.ts
  core/
    app.ts / ui.ts / view.ts      界面、交互、缩放、回放控制
    store.ts / library.ts         题库、进度、上次题目存储
    audio.ts / fx.ts              音效与落子特效
  game/
    adapter.ts                    游戏规则接入
    rules.ts                      推理规则
    logic.ts                      逻辑解题回放
    render.ts / state.ts          SVG 渲染与盘面状态
    validate.ts / solver.ts       实时校验与回溯求解
    puzzles.ts / puzzles-data.ts  题库加载与静态题库
```

## 命令

```bash
npm run dev       # 开发服务
npm start         # 开发服务 + 自动打开浏览器
npm run build     # tsc --noEmit + vite build
npm run gen       # 重新生成题库
npm run check     # 审计题库
npm run verify    # 参考解、逻辑回放与交互验证
npm run audit     # 逐题审计逻辑解题
```

## 尺寸与棋盘支持

| 项目 | 范围 / 说明 |
|------|------|
| 棋盘形状 | **n×n 正方形**（拉丁方规则决定：每行每列必须恰好是 1..n）；异形棋盘不支持 |
| 内置题 | 4×4、5×5、6×6 |
| 自定义题板（本批新增） | 4×4 – 9×9：网格里点选预填数字，下方四个输入框录入上 / 下 / 左 / 右盘外线索（空白或 0 = 不给线索），支持编辑回填与删除；4–6 阶用整行 / 整列排列定式，7–9 阶用可见高度上下界定式 |
| 自定义题校验 | 宽高必须相同、边长 4–9、线索数量与值域 0..n、预填数字 1..n 且同一行 / 列不重复；不合法会阻止载入 / 保存并提示原因 |
| 编码上限 | 预填数字与线索都是 1 字符/格，因此 n ≤ 9（识图导入同样按 9 阶设计） |
| 识图导入 | 9×9（含盘外线索，本项目 `month.png` 可识别） |
| 旧数据兼容 | 题面 / 参考解 / 进度存档格式未变；自定义题条目沿用同一 `board` 编码，旧题库不受影响 |
